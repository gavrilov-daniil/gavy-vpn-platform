# Миграции: как не потерять свою

Drizzle применяет миграции по полю `when` в `_journal.json` и пропускает те, чей
таймстемп **не больше** последнего применённого. Молча: команда отвечает
«migrations applied successfully», а таблицы нет.

Эта грабля сработала в проекте трижды, поэтому правило простое:

**`when` новой записи должен быть строго больше максимального существующего.**

Проверить перед коммитом:

```bash
python3 -c "
import json; j=json.load(open('packages/db/drizzle/meta/_journal.json'))
w=[e['when'] for e in j['entries']]
print('возрастает:', all(w[i]<w[i+1] for i in range(len(w)-1)), '| максимум:', max(w))
"
```

Отдельно: журнал этого проекта опережает системные часы, поэтому
`drizzle-kit generate` проставит **меньший** таймстемп, и сгенерированная
миграция не применится. При ручном добавлении бери `максимум + 10000`.

Проверка, что всё доехало:

```sql
select count(*) from drizzle.__drizzle_migrations;  -- должно совпасть с числом записей в _journal.json
```
